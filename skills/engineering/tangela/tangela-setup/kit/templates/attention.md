# Attention

What needs a person. One item per line, in this shape:

`- [ ] A<n>: <the question>. Settle with: <word> | <word>. Default if unanswered: <what happens>. Raised <YYYY-MM-DD> by <who>.`

Settling one changes `[ ]` to `[x]`, appends ` Settled <date>: <answer>.`, and adds a row to `decisions.tsv`.
